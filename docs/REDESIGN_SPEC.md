## Размеры

- Радиус карточек: `12`
- Радиус контролов (кнопки, инпуты, пилюли): `10`
- Толщина рамки: `StyleSheet.hairlineWidth` (не хардкодить `1`)
- Заголовок баланса: `36 / 500`
- Обычный текст: `13-14 / 400-500`
- Мелкий/подпись: `11-12 / 400-500`

## Компоненты и структура

### 1. `components/wallet/BalanceCard.tsx` — переделка
Убрать 3-колоночный ряд SOL/USDC/USDT как было. Новая структура сверху вниз:
1. `CurrencySwitch` (новый компонент) — сегмент-контрол `USD | SOL`, состояние `currency: 'usd' | 'sol'` живёт в `DashboardScreen`, не внутри карточки.
2. Заголовок баланса (36px) — значение зависит от `currency`: `formatUSD(totalUsd)` либо `${solBalance} SOL`.
3. Подпись под заголовком (12px, secondary) — обратная величина: `≈ X SOL` либо `≈ $X`.
4. `AddressCard` (новый компонент, см. ниже) — встроен сюда же, под балансом.

### 2. `components/wallet/AddressCard.tsx` — новый компонент
- Подпись `Ваш адрес` (НЕ "Public Key", нигде в UI это слово не должно фигурировать)
- Значение — сокращённый адрес (`shortAddress`, как было), моноширинным шрифтом
- Кнопка-иконка копирования справа (уже есть логика `handleCopyAddress` в dashboard — просто перенести)
- Ссылка `QR-код` — раскрывает/скрывает `react-native-qrcode-svg` с реальным адресом (это уже зависимость проекта, никакой новой библиотеки не нужно)

### 3. `components/wallet/CurrencySwitch.tsx` — новый компонент
Пропсы: `value: 'usd' | 'sol'`, `onChange: (v) => void`. Два таба в одной пилюле, активный — заливка `accent`, текст `#fff`.

### 4. `app/(tabs)/payments.tsx`
- Токен-селектор (уже есть `TokenSelector.tsx`) — только рестайл под новую палитру, логику не трогать
- Поле адреса — рестайл под `surface`/`border` токены, иконка `expo-camera` scan справа (сканирование уже должно быть в проекте — если нет, добавить как отдельную задачу, не блокирует рестайл)
- Сумма — использовать тот же `CurrencySwitch`, но с вариантами `SOL | USD` вместо `USD | SOL` (порядок ролью не важен, просто дефолт — SOL, раз это экран отправки конкретного токена)

### 5. `app/(tabs)/settings.tsx`
Уже переведён на трёхпозиционный список сетей в прошлой правке — только заменить хардкод-цвета на новые токены выше, ничего структурно не менять.

## Чего не делать

- Не трогать бизнес-логику (`stores/*`, `services/*`) в рамках этой задачи — это чисто визуальный слой поверх уже работающих (после прошлых фиксов) данных.
- Не убирать `PQBadge` и бейдж сети с dashboard — просто не входят в зону этой правки.
- Не заменять `expo-linear-gradient` карточку сплошным фоном автоматически везде — там, где градиент декоративный (не несёт смысла), можно убрать, но не обязательно в рамках этой правки.
- Не менять формат хранимых данных (`TokenBalance`, `TransactionRecord` и т.д.) — только их отображение.
- Не переносить логику курса/конвертации в компоненты — `CurrencySwitch` и `AddressCard` должны быть презентационными (получают готовые значения через пропсы), вся арифметика остаётся в экранах.
