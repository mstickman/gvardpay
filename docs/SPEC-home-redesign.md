## Компонент: `AddressCard` (новый)

Карточка `#16181D`, border `0.5px solid #2A2D33`, radius `12px`, padding `14px`.

- Верхняя строка: слева лейбл `Ваш адрес` (11px/500, `#8B9099`, с иконкой `wallet` 13px перед текстом), справа — тап-зона `Показать QR` (11px/500, `#4C7EFF`, иконка `qrcode`).
- Вторая строка: адрес в формате `XXXX...YYYY` (первые 4 / последние 4 символа base58), 14px/500, `font-variant: monospace` — и кнопка-иконка копирования справа: квадрат 30×30, radius 8px, фон `#1E2126`, иконка `copy` 15px.
- По тапу на карточку/иконку — копия в буфер через `expo-clipboard`, снизу на 1.8 сек показывать плашку `Адрес скопирован` (фон `#1E2126`, border `#2A2D33`, radius 10px, текст `#34D399` 12px, иконка `check`).
- По тапу на "Показать QR" — разворачивается блок с QR (react-native-qrcode-svg, 120×120, светлый фон `#F5F6F7`) под адресом, с отступом сверху `12px` и разделителем `0.5px solid #2A2D33`.

Термин **"Публичный ключ" нигде в интерфейсе не появляется** — везде только "адрес".

## Компонент: `BalanceCard` — переключатель валюты

Сегмент-контрол над самим числом баланса: два таба `USD` / `◎ SOL`, контейнер `#16181D`, radius 8px, padding 2px, активная кнопка — заливка `#4C7EFF`, текст `#fff` 12px/500; неактивная — прозрачный фон, текст `#8B9099`.

- Большое число баланса: 36px/500, `letter-spacing:-0.4px`.
- Под ним — обратный курс мелким текстом: 12px, `#8B9099` (например, при выбранном USD показывать `≈ 6.42 SOL`, и наоборот).
- Источник курса — уже реализованный `getSolPriceUsd()` (см. `services/price.ts`), никакой новой логики цены не писать.

## Экран `payments.tsx` — поле адреса и сумма

- Выбор токена — три пилюли в ряд (`SOL` / `USDC` / `USDT`), `#16181D`/`#2A2D33`, radius 10px, активная — `#4C7EFF`.
- Поле адреса: `#16181D`, border `#2A2D33`, radius 10px, padding `11px 13px`, внутри — `TextInput` + иконка `scan` (`#8B9099`, тап открывает `expo-camera` для сканирования QR — уже есть как зависимость, механику сканирования не менять, только визуал поля).
- Сумма — тот же сегмент-контрол SOL/USD, что и на главной, число 32px/500 (чуть меньше, чем баланс на главной — это ввод, не витрина).

## Что НЕ делать

- Не использовать `LinearGradient` нигде в этих экранах — только плоская заливка.
- Не добавлять тени/blur/свечение.
- Не менять логику `getTransactionHistory`, `getSolPriceUsd`, `requestAirdrop` — это уже рабочий код, спека только про визуал и про добавление адрес-карточки/переключателя.
- Не переименовывать `publicKey` в сторах/сервисах — переименование касается **только текста в UI** ("Ваш адрес" вместо любого упоминания "Public Key"), не имён переменных/полей в коде.
- Не убирать существующий `NETWORK_LABELS`/`NETWORK_COLORS` из dashboard.tsx — цвета сетей там уже совпадают с этой спекой, переиспользовать как есть.
- Радиус карточек — только `12px`, для мелких элементов (поля, пилюли, кнопки) — `10px`, для маленьких иконок-кнопок — `8px`. Не смешивать.
- Border везде `0.5px`, не `1px`.
